# Code of Conduct

Be specific, technical, and respectful.

Do not publish credentials, private logs, exploit details, or another person's
identifying data in issues, pull requests, or discussions.

Security reports belong in private channels described in [SECURITY.md](SECURITY.md).
Do not file public issues for vulnerabilities.

Maintainers may remove content or restrict participation when a contribution
creates safety or harassment risk. There is no separate enforcement team and no
response-time promise.

Contact: `nyk@builderz.dev`
